🌦️ Weather Data Analysis System

Weather monitoring, database management and data visualization

Welcome to Weather Data Analysis System

This application helps you manage weather records for different cities. You can add new records, update existing information, search by city, delete records, calculate average temperatures, and visualize weather information using graphs.

About This Project

The Weather Data Analysis System is developed using Python and Flask for backend operations, MySQL for storing weather information, HTML and CSS for the user interface, and Matplotlib for data visualization.

Weather Data Analysis System | Python | Flask | MySQL | Matplotlib
